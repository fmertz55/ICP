# BioSystems submission checklist: ICP Hypothesis Paper

## Complete

- Journal-facing LaTeX master and PDF
- Article type identified as Hypothesis Paper
- Abstract at or below 250 words
- Seven keywords
- Five highlights, each at or below 85 characters
- Corresponding-author email
- Data/code availability, ethics, funding, competing-interest, CRediT, and AI-use statements
- Numbered citations with resolved bibliography
- Figure-free submission source and PDF
- Deterministic source ZIP with hashes verified against repository inputs
- SHA-256 sidecars for the source ZIP and review PDF
- Canonical JSON build manifest with input, artifact, and Git metadata
- Cover-letter and presubmission-inquiry drafts
- Related-manuscript overlap statement
- Clean LaTeX build and visual PDF review

## Author-supplied or external actions still required

- Confirm or replace the affiliation “Independent Researcher”
- Supply the full postal address required by the submission system
- Supply the corresponding author's ORCID
- Confirm the no-external-funding and no-competing-interest declarations
- Create immutable, DOI-backed releases of both repositories (for example,
  through Zenodo) and replace repository-only citations with release DOIs
- Post distinct preprints and insert their identifiers in both manuscripts
- Obtain written editorial guidance before simultaneous submission of the pair
- Add the related manuscript's DOI or BioSystems manuscript number when one is
  available
