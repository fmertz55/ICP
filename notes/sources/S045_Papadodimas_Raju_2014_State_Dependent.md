## Native result

The authors construct black-hole interior operators in AdS/CFT using a map
that depends on the CFT state. Within the specified equilibrium/near-equilibrium
code of states, correlators reproduce local effective field theory and address
the strong-subadditivity tension.

## Common-schema mapping

The same microscopic operator need not represent the same bulk observable
across all states. Reconstruction is indexed by a state/code subspace and an
allowed measurement family.

## Boundary and ICP relationship

This is a concrete rival to state-independent carrier language. Its validity
outside the selected small algebra and code subspace is contested; it cannot be
silently promoted to a global observer-independent localization claim.
