## Native result

The paper relates bulk locality and subregion reconstruction in AdS/CFT to
quantum error correction, particularly operator-algebra QEC. A logical bulk
operator can have multiple boundary reconstructions on a code subspace without
being an independent copy of the information.

## Common-schema mapping

The candidate record is an encoding map, the observable is a logical operator,
and erasure of boundary regions supplies the intervention. Reconstructability
depends on the code subspace and boundary algebra.

## Boundary and ICP relationship

QEC is a formal encoding relation, not by itself a dynamical history-bearing
carrier. ICP adds content only if it predicts which physical code/geometry
forms or changes under intervention beyond standard holography.
