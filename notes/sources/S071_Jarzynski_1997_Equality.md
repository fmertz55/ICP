# S071 — Jarzynski (1997), Nonequilibrium Equality for Free Energy Differences

## Bibliographic record

- DOI: <https://doi.org/10.1103/PhysRevLett.78.2690>
- Status: peer-reviewed theoretical article

## Native result

For an ensemble driven between parameter values under the paper's assumptions,
the exponential work average equals the equilibrium free-energy difference:
`<exp(-beta W)> = exp(-beta Delta F)`.

## Common-schema mapping

The protocol and preparation define a path ensemble whose rare work values
matter. This is a path-law constraint, not a measure of stored memory.

## Boundary and ICP relationship

Correct initial equilibrium, work definition, dynamics, sampling of rare
events, and system-bath assumptions are essential.
